# Code of Conduct

Participants in Sindook spaces should be respectful, constructive, and focused on the work. Harassment, discrimination, threats, personal attacks, or sharing another person's private information are not acceptable.

This applies to issues, pull requests, discussions, and other project communication. Report a project concern through [GitHub Issues](https://github.com/ruddro-roy/sindook/issues/new/choose). Do not include sensitive personal information in a public report.

Project maintainers may remove comments or contributions that do not meet this standard.
